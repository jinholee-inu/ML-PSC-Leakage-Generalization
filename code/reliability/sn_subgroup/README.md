# Sn-subgroup calibration and mixture-of-experts analysis

This folder contains the authentic leakage-controlled subgroup analysis used for the
Sn-only and mixed Pb–Sn reliability stress test.

## Scripts

- `subgroup_calibration_moe.py`
  - defines Sn-only and mixed Pb–Sn B-site domains from the frozen composition assignments
  - uses publication-disjoint historical out-of-fold predictions through 2018 for model development
  - compares identity, bias-only, and ridge-shrunk affine calibration
  - compares subgroup Random-Forest expert configurations
  - selects convex global/expert mixtures with a DOI-level one-standard-error rule
  - evaluates the selected policy once on the untouched 2019–2021 chronological cohort
  - reports publication-balanced metrics with DOI-cluster bootstrap confidence intervals

- `verify_subgroup_calibration_moe.py`
  - verifies support counts and paired record sets
  - reconciles frozen global predictions
  - checks historical/future DOI separation
  - independently verifies one-standard-error selections and metric calculations

The original Word/PDF report builder and Figure 9 image files are intentionally excluded because
they do not generate the scientific results.

## Archived design

Sn-only:
- historical: 389 records / 83 DOI groups
- future: 155 records / 30 DOI groups

Mixed Pb–Sn:
- historical: 274 records / 57 DOI groups
- future: 98 records / 25 DOI groups

Across all eight domain-target combinations, the historical DOI-level one-standard-error rule
selected identity calibration, mixture alpha = 0, and the frozen global policy.

The independent verifier passed 22/22 checks.
